## 📌 1. الفكرة والهدف العام
* 🎯 **تتبع الحمل بدقة:** يتيح الحساب التلقائي لعمر الحمل بالأسابيع والأيام بناءً على تاريخ آخر دورة شهرية (LMP)، وتحديد تاريخ الولادة المتوقع.
* 👶 **متابعة نمو الجنين:** يقارن حجم الجنين أسبوعياً بأشياء حقيقية مألوفة (مثل الفواكه والخضروات)، مع عرض معلومات علمية وتفصيلية عن التطور الجسدي والأعراض المتوقعة لكل أسبوع.

---

## 🛠️ 2. الأقسام والميزات الرئيسية
* 🏠 **الرئيسية (Home):** لوحة معلومات تفاعلية تعرض نسبة تقدم الحمل، الشريط الزمني، الشهر الحالي، حجم الجنين، النصائح، والأعراض الشائعة.
* 🩺 **الزيارات الطبية والأطباء (Visits):** لتسجيل زيارات الأطباء والمستشفيات، وتدوين الملاحظات، التشخيص، الأدوية، والتحاليل الطبية مع إمكانية تنظيمها وترتيبها حسب الطبيب.
* 📊 **فحوصات السونار (Sonar):** مساحة مخصصة لتسجيل تفاصيل السونار (مثل قياسات CRL و BPD و FL، نبض الجنين، ووزن الجنين المقدر) مع إمكانية إرفاق الصور وملفات الـ PDF.
* 📄 **التقرير الطبي (Medical Report):** خاصية لتوليد تقرير شامل ومنسق لجميع تفاصيل الحمل والزيارات وقابلة للطباعة أو الحفظ بصيغة PDF.
* 👩‍👧 **إدارة الحمل المتعدد:** يتيح للمستخدمة إدارة أكثر من سجل حمل (في حالات الحمل السابقة أو الحالية) والتبديل بينها أو إضافة حمل جديد.

---

## ⚙️ 3. التقنيات البرمجية المستخدمة
* ⚡ **بنية برمجية موحدة (Single-File Application):** التطبيق مكتوب بملف HTML واحد يدمج الهيكل (HTML)، والتصميم (CSS) المتجاوب مع الوضعين الداكن والفاتح، والمنطق البرمجي (JavaScript) لضمان السرعة وسهولة النشر.
* 💾 **التخزين المحلي (LocalStorage & IndexedDB):** يعتمد على تخزين بيانات المستخدمة محلياً على المتصفح لضمان الخصوصية، مع استخدام قاعدة بيانات IndexedDB لحفظ الملفات الكبيرة والصور والمرفقات الطبية.
* 🔄 **النسخ الاحتياطي والاستعادة:** يوفر ميزة تنزيل واستعادة النسخة الاحتياطية للبيانات بصيغة ملفات JSON.
